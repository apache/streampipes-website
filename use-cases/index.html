What people build with StreamPipes.

Scenarios we see often. Each page lists the adapters, processors and sinks involved and links to the guide. All of it runs on a standard installation.

Condition monitoring with OPC UA
Connect machines over OPC UA, keep an eye on the values that matter, and get a message when a trend or a threshold needs attention.
Read the use case
PLC data to Kafka and InfluxDB
Read Siemens S7 and Modbus controllers, clean up units and field names, and forward the events to the systems IT already runs.
Read the use case
MQTT and a unified namespace
Subscribe to the topics your broker already carries, turn raw payloads into typed streams with context, and publish the results back into the namespace.
Read the use case
Anomaly detection with Python Functions
Train a model on a dataset in a notebook, run it on the live stream as a StreamPipes Function, and get the predictions back as a stream.
Read the use case
Alarms, events and notifications
Receive OPC UA alarms and events, measure how long states last, and send a message to the right channel when something changes.
Read the use case
Alarm history from WinCC
Read the alarm archives a Siemens WinCC system writes, turn them into a stream, and find out which alarms keep coming back and how long they stay active.
Read the use case
Machine state tracking
Turn the running, blocked and fault signals of a machine into states, measure how long each state lasts, and see where the time went per line and shift.
Read the use case
Quality control with statistical limits
Attach control and warning limits to a measurement, get an alert the moment a value breaks them, and spot a slow drift before a part goes out of spec.
Read the use case
Reduce data before it leaves the plant
